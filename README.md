# HUNGRY

Дневник питания, который не желает тебе добра. Чёрный, вишнёвый, розовый, честный.
Еда, вода, вес, заметки, история и статистика — без аккаунта и без сервера.

**Публичная версия:** https://svinota-cry.github.io/hungry/

## Что внутри

- «Сегодня»: калории, кольцо прогресса, макросы, вода, быстрый вес, последние записи.
- «Дневник»: записи по приёмам пищи и дням, редактирование, удаление с отменой.
- «Поиск»: 138 встроенных продуктов, фильтры «безопасные» / «красные флаги» / «мои», свои продукты.
- «История»: календарь-хитмэп по месяцам и детальный разбор дня.
- «Статистика»: периоды 7 / 30 / 90 дней, графики калорий, макросов, воды и веса.
- «Заметки»: тексты и настроения, фильтр архива.
- «Профиль»: цели, вес, настройки приватности / движения / плотности, экспорт и импорт JSON.
- Данные лежат только в браузере: `localStorage`, ключ `hungry.v2`.
- Первый запуск показывает 4 недели демо-данных; их можно стереть в профиле.

## Локальный запуск

Нужен Node.js 20.19+ (лучше 22 или 24).

```bash
npm install
npm run dev
```

Открой адрес, который напечатает Vite (обычно `http://localhost:5173/`).

Сборка и локальный предпросмотр production-версии:

```bash
npm run build
npm run preview
```

Проверка типов и линтера:

```bash
npm run build   # tsc -b && vite build
npm run lint    # oxlint
```

## Где что лежит

- `index.html` — HTML-оболочка.
- `src/main.tsx` — точка входа React.
- `src/App.tsx` — приложение, hash-роутинг, модалки, тосты.
- `src/views/` — семь экранов.
- `src/components/` — оболочка, графики, модалка еды, онбординг, UI-кит.
- `src/lib/store.tsx` — состояние и все действия с данными.
- `src/lib/seed.ts` — демо-данные на 4 недели.
- `src/data/foods.ts` — база продуктов и поиск.
- `src/styles/` — визуальный слой (`base`, `ui`, `views`, `responsive`).
- `public/fonts/` — локальные шрифты (Playfair Display, Golos Text, JetBrains Mono).
- `package.json` — скрипты `dev`, `build`, `lint`, `preview`.

## Публикация

Сайт живёт на GitHub Pages из ветки `gh-pages`:

```bash
npm run deploy
```

Команда собирает production-версию и выкладывает `dist` в ветку `gh-pages`.
Первый деплой уже сделан; повторяй команду после изменений.

- `vite.config.ts` использует `base: "./"`, поэтому сборка работает и в корне домена, и в подпапке `/hungry/`;
- `public/404.html` возвращает случайные пути в приложение (hash-роутинг не требует серверных rewrite-правил);
- исходники и история остаются в `main`, собранная версия — в `gh-pages`.

## Важно

HUNGRY — не медицинский сервис и не диета. Это дневник. Если еда, вес или цифры
перестали быть просто цифрами, поговори с живым человеком: близким, врачом, психологом.
